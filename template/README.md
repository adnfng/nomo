# Your Nomo page

This repo is a personal page. `human.md` is the whole thing, and it's live at `https://nomo.md/yourusername`.

1. Keep the repo public and named `.nomo`.
2. Edit `human.md`. Swap the name, links and `assets/me.jpg` for yours.
3. Push. The page updates within a minute.

Or ask your agent: `Set up my Nomo page. Follow AGENTS.md`

Syntax and examples: https://nomo.md/docs
